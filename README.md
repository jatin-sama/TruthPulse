TruthPulse is an AI-driven misinformation detection system designed to scan, analyze, verify, and explain online content in real-time. Built specifically for rapid crisis scenarios like pandemics, elections, conflicts, and climate emergencies  TruthPulse empowers users with accurate, verified, and contextual truth at the speed of the internet.

This project was built during mumbaihacks agentic hackathon to help fight the growing crisis of misinformation.
